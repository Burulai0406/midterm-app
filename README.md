# Midterm Project: Flutter + Python Flask

## Features
- Flutter cross-platform app
- Python Flask backend with SQLite
- State management with Bloc (Products + Cart)
- Product list, detail page, shopping cart
- CORS enabled

## How to run
1. Backend: `cd backend && python server.py`
2. Flutter: `flutter run -d chrome`
